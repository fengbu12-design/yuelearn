# 粵語自習室 · 香港話三十課

把《粵語（香港話）教程（修訂版）》三十課整理成一個可以自己讀、自己聽的靜態網站。
純靜態：沒有後端、沒有資料庫、不收集任何個人資料，所有進度與筆記都存在你自己的瀏覽器裏。

## 裏面有什麼

每一課都是同一套結構：

| 板塊 | 內容 |
|---|---|
| 課文 | 逐句粵語 + 粵拼 + 譯文 + 語法提示，點句子即讀，可切慢速 |
| 影片 | 教材配套錄音示範，可用 0.75×–1.25× 播放 |
| 重點詞彙 | 詞條卡片，點即讀，星號加入生詞本 |
| 補充詞彙 | 教材補充部分，格子形式 |
| 重點理解 | 教材用整節篇幅講的易混詞 |
| 語音／語法講解 | 該課的發音與句式重點 |
| 粵語趣談與港式文化 | 粵語的來源、演變、俗語典故 |
| 教材之外 | 粵普對照、情境延伸、易錯提醒 |
| 練習 | 六道選擇題，即時解析 |
| 粵字辨認 | 高頻粵字 |
| 短文朗讀 | 逐句音頻，可整段播 |

另有：全文搜尋、生詞本、筆記（句級批註與課級筆記）、跟讀模式（每句後留白 2 秒）、
遮蔽練習（藏漢字或藏粵拼）、夜讀主題、教材原頁對照。

## 目錄

```
index.html          單頁應用（樣式與腳本都內聯，離線可開）
data/course.js      課程結構與三十課索引
data/lessons.js     三十課全部內容
audio/              1525 個朗讀音頻（課文、短文、會話，各含正常與慢速）
pages/              367 張教材頁圖
video/              30 個教材配套影片，已改名為 01.mp4…30.mp4
.nojekyll           告訴 GitHub Pages 不要用 Jekyll 處理
```

## 本機打開

雙擊 `index.html` 就能用。若影片不播放，改用本機伺服器：

```bash
python -m http.server 8765
# 然後開 http://127.0.0.1:8765
```

## 部署

見 `_build/發佈到GitHub.md`（在原始專案裏）。本站是純靜態檔案，丟到任何靜態託管都能跑：
GitHub Pages、Netlify、Cloudflare Pages 都行。

## 朗讀語音

課文、短文、會話的音頻是預先產生的 mp3，任何瀏覽器都能播。
講解、詞彙、例句用的是瀏覽器自帶的語音合成，不同瀏覽器音色差別很大——
頂欄的「語音」按鈕可以自己挑一個聽得順的。建議用 Edge（內建粵語音色）。
