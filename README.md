# 粵語自習室 · 香港話三十課

把《粵語（香港話）教程（修訂版）》三十課整理成一個可以自己讀、自己聽的靜態網站。
純靜態：沒有後端、沒有資料庫、不收集任何個人資料；進度與筆記都存在你自己的瀏覽器裏。

## 裏面有什麼

每一課結構一致：

| 板塊 | 內容 |
|---|---|
| 課文 | 逐句粵語 + 粵拼 + 譯文 + 語法提示，點句子即讀，可切慢速 |
| 影片 | 教材配套錄音示範，可用 0.75×–1.25× 播放 |
| 重點詞彙 | 詞條卡片，點即讀，星號加入生詞本 |
| 補充詞彙 | 教材補充部分，格子形式 |
| 重點理解 | 教材用整節篇幅講的易混詞 |
| 語音／語法講解 | 該課的發音與句式重點（下編為「特有詞講解」） |
| 粵語趣談與港式文化 | 粵語的來源、演變、俗語典故 |
| 教材之外 | 粵普對照、情境延伸、易錯提醒 |
| 練習 | 選擇題，即時解析 |
| 粵字辨認 | 高頻粵字 |
| 短文朗讀／會話 | 逐句音頻，可整段播（下編為會話聆聽練習） |

全站功能：

- **全站搜索**：課程／418 條詞彙／450 句課文，支援粵拼，點結果跳課並定位
- **聽力練習**：聽音選義、聽寫兩種模式，用教材原聲
- **複習**：生詞本按間隔重複（Leitner 1/2/4/8/16 天）排程，三檔自評
- **循環洗腦**：本課詞彙／課文、生詞本、今日複習、全書詞彙連續播放，跑步可用
- **語音總覽**：20 課語音點匯成一頁，可搜可跳
- **相關課**：按詞彙復用自動推薦關聯課
- 生詞本、筆記（句級批註＋課級筆記）、跟讀（每句留白 2 秒）、遮蔽練習、夜讀、教材原頁對照

## 目錄

```
index.html          單頁應用（樣式與腳本內聯）
data/course.js      課程結構與三十課索引
data/lessons.js     三十課全部內容
audio/              4026 個 mp3：課文 1525（常速／慢速）＋ 講解與詞彙 2501
audio/x/            講解類音頻，內容尋址命名（同一句話永遠同一個檔）
pages/              367 張教材頁圖
video/              30 個教材配套影片，已改名為 01.mp4…30.mp4
.nojekyll           告訴 GitHub Pages 不要用 Jekyll 處理
```

## 本機打開

雙擊 `index.html` 就能用。若影片不播放，改用本機伺服器：

```bash
python -m http.server 8765
# 然後開 http://127.0.0.1:8765
```

## 部署

本站是純靜態檔案，丟到任何靜態託管都能跑：GitHub Pages、Netlify、Cloudflare Pages。
原專案用 `publish-site.bat` 一鍵發布到 GitHub Pages。

## 朗讀語音

**課文、短文、會話、講解、詞彙、例句的音頻全部是預先生成的 mp3**，任何瀏覽器、任何裝置
都能播放，不依賴瀏覽器是否內建粵語音色（早期版本講解類靠語音合成，會讀錯字，已改掉）。

頂欄「語音」按鈕只影響極少數沒有預生成音頻的短文字（例如卡片標題）的朗讀。
